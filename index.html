🖥️ OS Emulator

A full x86 PC, emulated in WebAssembly, running entirely in this browser tab.

Boot something

Everything runs locally in your browser — nothing is uploaded anywhere.

Network

Off by default. When on, the guest gets a real network card and can reach the internet — but only by routing its traffic through relay.widgetry.org, a public relay run by the v86 project's community, not by us or Anthropic. Fine for poking around inside the guest; don't rely on it for anything sensitive.

Demo Linux

A small bundled Linux — boots in a few seconds, no download needed.

Your own ISO / IMG

Pick a disk image from your computer. Small Linux distros work best; very old Windows (98/2000-era) can work but is slow and unreliable. Modern Windows isn't realistic to run this way.
